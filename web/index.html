Game Overlay

Popout a transparent HUD window showing DPS, zone, loot value, and trader capacity. The overlay sits on top of the game — use your OS window manager to keep it always-on-top.

No OBS / no browser extensions needed.
Press O to open the overlay from any view.
URL: http://localhost:7777/overlay
Always-on-top tips:
• Windows: Win+Shift+→ or use OnTopReplica
• macOS: System Settings → Desktop & Dock → uncheck "Tile windows by holding option"
• Linux: Right-click title bar → "Always on Top"
• Run from terminal: start msedge --app=http://localhost:7777/overlay (Edge app mode removes browser chrome)
